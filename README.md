# Another Config Manager

| Version | Support Status |
|--------|---------------|
| 26.1.2 | Supported |
| 1.21.1 | Supported |
| 1.20.1 | Not Supported |
| Older Versions | Not Supported |

Config browser and editor for NeoForge `ModConfigSpec` trees: sections, buffered Save/Undo, CSV tables for string lists, and declared color editors.

Requires **Iskandert's Library** (`iska_lib`) as a separate mod.
