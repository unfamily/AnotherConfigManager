# Another Config Manager

| Version | Support Status |
|--------|---------------|
| 26.1.2 | Supported |
| 1.21.1 | Supported |
| 1.20.1 | Not Supported |
| Older Versions | Not Supported |

Standalone config browser and editor for NeoForge `ModConfigSpec` trees: sections, buffered Save/Undo, CSV tables for string lists, and declared color editors.

Does not require Iskandert's Library or Utilities. Other mods (including Library/Utils) may declare a dependency on ACM.
